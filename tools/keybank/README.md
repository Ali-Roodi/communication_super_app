# ابزارهای ویندوزی هم‌رسان

این پوشه دو ابزار دارد. هر دو کد فعال‌سازی و فایل کلید اعضا را می‌سازند:

| ابزار | برای چه کسی | چطور اجرا می‌شود |
|---|---|---|
| **پنل صدور** | مسئول سازمان | فایل نصب `HamresanPanel-1.6.0.msi`. جاوا لازم ندارد. |
| **ابزار خط فرمان** | تیم فنی | `hamresan-keybank.cmd`. جاوا ۱۱ یا بالاتر لازم دارد. |

راهنمای کامل پنل با تصویر: `docs/mentor/Hamresan_Issuance_Panel_Guide_FA.pdf`

هر دو ابزار از کد رمزنگاری خود برنامه ساخته می‌شوند
(`android/app/src/main/kotlin/.../smscrypto/`). پس هر فایلی که بسازند، برنامه هم
می‌تواند آن را بخواند. این کد را هرگز کپی نکنید.

## پنل صدور

پنل سه منو دارد:

- **فعال‌سازی بین‌سازمانی:** کد ۶ نویسه‌ای دستگاه را بنویسید تا کد فعال‌سازی برنامهٔ تجاری نشان داده شود.
- **فعال‌سازی سازمانی:** همین کار برای فایل نصب سازمانی. این دو کد با هم فرق دارند و هیچ‌کدام نسخهٔ دیگر را باز نمی‌کند.
- **فایل کلید اعضا:** عضو را اضافه می‌کنید و پنل برای او یک فایل کلید و یک رمز می‌سازد. این منو فقط با فایل مرجع (`authority.hka`) و رمزش باز می‌شود.

چند نکتهٔ مهم:

- فایل کلید هر عضو فقط کلید و گواهی خود اوست. نام و شمارهٔ کس دیگری در آن نیست.
- افزودن، ویرایش، «گوشی گم شد» و حذف فقط فایل همان عضو را عوض می‌کند. به بقیهٔ اعضا چیزی لازم نیست بدهید.
- فایل و رمز را از دو راه جدا به عضو بدهید.
- رمز مرجع هیچ‌جا ذخیره نمی‌شود. بخش کلید با دکمهٔ «قفل»، با بستن برنامه و بعد از ۱۰ دقیقه کار نکردن قفل می‌شود.
- هر صدور «همه یا هیچ» است. اگر خطایی پیش بیاید، هیچ فایلی عوض نمی‌شود.

آزمایش نسخهٔ نصب‌شده بدون باز شدن صفحه:

```
HamresanPanel.exe --self-test <پوشه>
```

نتیجه در `<پوشه>\self-test.txt` نوشته می‌شود.

## ابزار خط فرمان

### ۱. ساختن مرجع (فقط یک بار)

```
hamresan-keybank init authority.hka
```

رمزی با دست‌کم ۱۲ نویسه می‌خواهد. هر کس این فایل و رمزش را داشته باشد، برای کل
سازمان کلید می‌سازد. آن را روی رایانهٔ بدون اینترنت نگه دارید و یک پشتیبان جدا بگیرید.

### ۲. گذاشتن کلید عمومی مرجع در برنامه (فقط یک بار)

```
hamresan-keybank public authority.hka
```

خروجی یک خط طولانی است و محرمانه نیست. آن را در
`lib/features/keybank/services/trust_anchors.dart` بگذارید.

### ۳. نوشتن فهرست اعضا (`roster.csv`)

در Excel با قالب «CSV UTF-8» ذخیره کنید:

```
organization,نام سازمان
name,phones,generation
علی رضایی,09121111111;02188776655
مریم احمدی,09122222222
```

- هر عضو دست‌کم یک شمارهٔ همراه (`09…`) لازم دارد. کلید و گواهی او از **اولین شمارهٔ همراهش** ساخته می‌شود، پس ترتیب شماره‌ها را عوض نکنید.
- چند شماره را با `;` جدا کنید.
- `generation` اختیاری است و پیش‌فرض آن ۰ است. اگر گوشی عضوی گم شد، این عدد را یکی زیاد کنید تا کلید تازه بگیرد.

### ۴. ساختن فایل‌ها

```
hamresan-keybank issue authority.hka roster.csv out
```

برای هر عضو فایل `out\<شماره>.hkb` ساخته می‌شود و رمزها در `out\passwords.csv` می‌آید.
اجرای دوباره کلید و رمز هیچ عضو قبلی را عوض نمی‌کند.

### ۵. بررسی یک فایل (اختیاری)

```
hamresan-keybank inspect out\09121111111.hkb authority-public.txt
```

`authority-public.txt` همان خروجی مرحلهٔ ۲ است.

### کد ۱۶ نویسه‌ای (وقتی فرستادن فایل ممکن نیست)

```
hamresan-keybank code authority.hka roster.csv 09121111111
```

این کد را تلفنی برای عضو بخوانید. عضو آن را با همان رمز فایل در «بانک کلید ← ساختن کلید با کد» وارد می‌کند و همان کلید ساخته می‌شود.
کد هیچ‌جا ذخیره نمی‌شود. کد و رمز را با هم نفرستید: این دو با هم کلید امضای سازمان را هم در برنامه باز می‌کنند.

### ۶. ساختن کد فعال‌سازی

به فایل مرجع نیاز ندارد:

```
hamresan-keybank activation 4f339b
hamresan-keybank activation 4f339b --organization
```

خط اول کد نسخهٔ بین‌سازمانی را می‌سازد و خط دوم کد نسخهٔ سازمانی را.

برای اجرای خودکار، رمز مرجع را می‌شود در متغیر `HAMRESAN_KEYBANK_PASSWORD` گذاشت.

## ساختن ابزارها (برای تیم برنامه)

`JAVA_HOME` باید روی JDK 21 باشد.

```
android\gradlew -p tools\keybank test :panel:test
android\gradlew -p tools\keybank jar
android\gradlew -p tools\keybank :panel:packageReleaseMsi
```

- خروجی خط فرمان: `tools/keybank/build/libs/hamresan-keybank.jar`
- خروجی پنل: `tools/keybank/panel/build/compose/binaries/main-release/msi/`
- تصویرهای راهنمای پنل هنگام آزمون پنل در `tools/keybank/panel/build/previews/` ساخته می‌شوند.
- اگر پنل تغییر کرد، `packageVersion` را در `panel/build.gradle.kts` بالا ببرید و راهنمای پنل را هم به‌روز کنید.

پوشهٔ `dev/` مرجع آزمایشی است، کلید خصوصی دارد و وارد git نمی‌شود. برنامه فقط وقتی به
آن اعتماد می‌کند که با `--dart-define=HAMRESAN_DEV_ANCHOR=true` ساخته شده باشد.
