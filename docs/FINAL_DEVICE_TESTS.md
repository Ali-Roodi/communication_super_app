# هم‌رسان — فهرست تست نهایی روی دو گوشی

هر قابلیتی که ساخته می‌شود، مواردی را که فقط با **دو گوشی واقعی و شبکهٔ واقعی**
قابل امتحان است همین‌جا اضافه می‌کند (در همان کامیت). شبیه‌ساز پیامک و تماس
ساختگی می‌سازد، ولی رفتار اپراتور، دو سیم‌کارت، پیامک چندقسمتی و برنامه‌های
خودِ سازندهٔ گوشی را نشان نمی‌دهد. وقتی موردی روی دو گوشی قبول شد، تیک و تاریخ
بخورد؛ اگر رد شد، به `KNOWN_ISSUES.md` برود.

**آماده‌سازی:** گوشی «الف» و گوشی «ب»، هر دو با هم‌رسان به‌عنوان برنامهٔ پیامک
و تلفن پیش‌فرض، شارژ کافی برای چند پیامک. شماره‌ای بیرون از این دو گوشی
استفاده نشود.

## ۳. فهرست سیاه و سفید (ردیف ۱۰)

**پیامک دریافتی**
- [x] شمارهٔ «ب» (یا الگویی مثل `۰۹۱۲*` که آن را بگیرد) در فهرست سیاه: پیامک «ب» به «الف» نه در هم‌رسان می‌آید، نه اعلان، نه در برنامهٔ پیامک سازنده. ✓ ۱۴۰۵/۰۸/۱۳
- [x] «فقط فهرست سفید» با فهرست سفید خالی: پیامک «ب» نمی‌رسد؛ پیامک اپراتور (شمارهٔ کوتاه یا نام) می‌رسد. ✓ ۱۴۰۵/۰۸/۱۳ (پیامک اپراتور در این حالت جدا امتحان نشد)
- [x] «ب» در فهرست سفید: پیامکش می‌رسد. ✓ ۱۴۰۵/۰۸/۱۳
- [x] «مخاطبین ذخیره‌شده هم مجازند» روشن و «ب» در مخاطبین: پیامکش می‌رسد. ✓ ۱۴۰۵/۰۸/۱۳
- [x] همین موارد با هم‌رسان بسته (از فهرست برنامه‌های اخیر کشیده شده). ✓ ۱۴۰۵/۰۸/۱۳ (برنامه در پس‌زمینه با `am kill`، فهرست سفید خالی)

**پیامک ارسالی**
- [x] «هیچ‌کس»: ارسال از گفتگو پیام «…مجاز نیست» می‌دهد، حبابی نمی‌سازد و «ب» چیزی نمی‌گیرد. ✓ ۱۴۰۵/۰۸/۱۳
- [x] پاسخ از اعلانِ پیامک: پیام «…مجاز نیست» و چیزی ارسال نمی‌شود. ✓ ۱۴۰۵/۰۸/۱۳
- [x] پیامک زمان‌بندی‌شده به شمارهٔ غیرمجاز: ارسال نمی‌شود و «ناموفق» می‌شود. ✓ ۱۴۰۵/۰۸/۱۳ (بعد از سه تلاش در ۶ دقیقه)
- [x] پیام گروهی که «ب» عضوش است: سهم «ب» ناموفق، بقیه ارسال. ✓ ۱۴۰۵/۰۸/۱۳ (گیرندهٔ دیگر سیم ۱ همان گوشی؛ تلاش مجدد بررسی نشد)

**تماس ورودی**
- [x] «هیچ‌کس» یا «ب» در فهرست سیاه: تماس «ب» زنگ نمی‌خورد و در «اخیر» دیده می‌شود. ✓ ۱۴۰۵/۰۸/۱۳
- [x] تماس به **هر دو سیم‌کارت** «الف» امتحان شود. ✓ ۱۴۰۵/۰۸/۱۳

**تماس خروجی**
- [x] شمارهٔ غیرمجاز از صفحه‌کلید هم‌رسان: پنجرهٔ «…مجاز نیست» روی صفحه‌کلید می‌آید و صفحهٔ تماس باز نمی‌شود. ✓ ۱۴۰۵/۰۸/۱۳
- [x] همان شماره از برنامهٔ دیگر (مثلاً مخاطبین سامسونگ): تماس قطع می‌شود و پیام کوتاه می‌آید. ✓ ۱۴۰۵/۰۸/۱۳
- [x] شماره‌های کوتاه (مثل `*140#` یا ۱۸۱۸) در «هیچ‌کس» هم کار می‌کنند. ✓ ۱۴۰۵/۰۸/۱۳

**پیام رمز و دفترچهٔ مخفی** (نسخهٔ سازمانی یا بین‌سازمانیِ فعال)
- [x] «ب» در فهرست سیاهِ پیامک دریافتی: پیام رمز «ب» هم نمی‌رسد. ✓ ۱۴۰۵/۰۸/۱۳

- [ ] در همان نصب تازه، زبانهٔ مخاطبین همهٔ مخاطبان را با نام و همهٔ شماره‌هایشان نشان می‌دهد و نام‌ها در «اخیر» و صندوق پیام‌ها درست است.
- [ ] در حین وارد شدن سابقه، پیمایش «اخیر» و رفتن به زبانه‌های دیگر روان است.
- [ ] روی گوشی‌ای با هزاران پیامک، نصب تازه: صندوق پیام‌ها در چند ثانیه پر می‌شود و در همین مدت «بایگانی»، جستجو و باز کردن یک گفتگو منتظر نمی‌مانند.

## ۷. صفحه‌بندی و پیمایش بی‌پایان

- [ ] بیش از ۵۰ گفتگو را بایگانی کنید: «بایگانی» با پیمایش تا آخرین گفتگو می‌رود.
- [ ] روی نصب تازه، در حین همگام‌سازی اولیهٔ پیامک‌ها، «بایگانی» را باز کنید: فهرست (یا «گفتگوی بایگانی‌شده‌ای نیست») می‌آید و چرخش نمی‌ماند؛ برگشت، صندوق اصلی را نشان می‌دهد.
- [ ] «اخیر» ← یک ردیف ← «سابقه»: برای کسی با تماس و پیامک زیاد، با پیمایش تا قدیمی‌ترین تماس و پیامک می‌رود و ترتیب زمانی درست است؛ برای شماره‌ای با یک تماس، برگه کوتاه است.
- [ ] جستجوی کلی (از نوار «اخیر»): برای کلمه‌ای پرتکرار، پیام‌ها با پیمایش تا قدیمی‌ترین نتیجه ادامه پیدا می‌کنند؛ تماس‌ها فقط یک ردیف برای هر شماره دارند، حتی برای کسی که مدت‌ها پیش تماس گرفته.
- [ ] «هرزنامه و مسدودشده» با تعداد زیاد: پیمایش روان است و «انتخاب همه» همه را می‌شمارد.
- [ ] نسخهٔ سازمانی: گفتگوی رمز و گروه رمز با بیش از ۵۰ پیام، با پیمایش به بالا پیام‌های قدیمی‌تر را نشان می‌دهند.
- [ ] نسخهٔ سازمانی: «تماس‌های مخفی» با بیش از ۵۰ تماس تا آخر پیمایش می‌شود؛ صفحهٔ یک مخاطب مخفی همهٔ تماس‌های خودش را نشان می‌دهد.
